# POMI
A Pomodoro App for study stuff.

"POMI- Temporizador Pomodoro para Estudio" es una app temporizador con técnica Pomodoro pensado para lograr metas de estudio más fáciles de cumplir.

Incluye:
-Un reproductor de música integrado, con una playlist predeterminada con músicas originales de autor. Tambien incluye un botón para agregar músicas desde tu dispositivo localmente.
-Temas de colores para interfaz predeterminados: Tomate, Océano, Bosque, Lavanda, Atardecer y Grafito. Para darle más onda y color a la hora de estudiar.
-Un creador de Metas de estudio, podés crear, darle nombres y marcar como completadas tus metas de estudio.

Solo está disponible para Android.
